# 公園さがし(プロトタイプ)

> **これはプロトタイプです。** 製品ではなく、オブジェクト指向UI(OOUI)と情報採餌理論の学習を目的に、画面構成と操作感を確かめるために作った試作品です。データはすべてダミーで、実在の公園・位置情報とは関係ありません。

子どもを連れて「今日行く公園を決める」ためのスマホアプリを想定した、HTML・CSS・JavaScript(単一ファイル、外部ライブラリなし)のプロトタイプです。画面サイズは iPhone 17(402×874pt)を想定しています。

## 見る・動かす

| ファイル | 内容 |
|---|---|
| `index.html` | カラー版 |
| `monochrome.html` | モノクロ版。画面構成だけを見るために、色と装飾を外したもの |
| `figma/` | Figmaに取り込むための静的HTML(モノクロ、iPhone 17の402×874)。下記参照 |

GitHub Pages を有効にすると、ブラウザだけで触れます。ローカルでは、ファイルをそのままブラウザで開いてください。
PCで開くと iPhone 17 の画面枠で表示され、ウィンドウに収まらない場合は縮小されます。スマホで開くと全画面になります。

## 設計

### モデルレイヤー

| オブジェクト | 属性 |
|---|---|
| 公園 | 名称、住所、写真、現在地からの距離(算出値) |
| 設置遊具(公園に設置された遊具) | 名称、公園内での設置場所 |
| 遊具(一般名詞) | 名称、特徴、対象年齢の目安 |

- 公園と遊具は多対多の関係で、設置遊具がその間にあたります。
- 公園の「遊びの対象年齢」は、設置遊具の対象年齢から算出します。距離と同じく、保存せず算出する値です。

### インタラクションレイヤー

| オブジェクト | コレクション | シングル |
|---|---|---|
| 公園 | あり | あり |
| 設置遊具 | あり | **なし** |
| 遊具 | あり | あり |

画面のつながり:

- 公園コレクション → 公園シングル → 設置遊具コレクション → 遊具シングル
- 遊具コレクション → 遊具シングル → 公園コレクション(その遊具がある公園に絞り込み)
- 設置遊具コレクションへは、公園シングルからのみ到達します。

### 公園コレクション(中心の画面)

公園の写真を並べたグリッドを、縦にも横にも自由にスライドして探します。

- **縦**:現在地から近い順(上が近い)。距離順に4件ずつ1行にしています。
- **横**:遊びの対象年齢(左が幼児向け、右が大きい子向け)。並びは行の中での順です。
- **中央のセル**:拡大して前面に出て、周りの写真に重なります。名称・距離・対象年齢・設置遊具のタグは、中央に寄ったセルにだけ表示されます。
- 縦横の意味に凡例が要らないよう、軸の値は中央のセルに出る情報(距離・対象年齢)でスクロールしながら分かる作りにしています。

## 操作

- **周辺のセルをタップ**:そのセルが中央に寄ります(選択)。
- **中央のセルをタップ**:公園シングルへ進みます。
- **中央のセルのタグ(設置遊具)をタップ**:その遊具がある公園に絞り込みます。複数選ぶと「選んだ遊具がすべてある公園」になります。外すには、上のバナーの「✕」「全解除」か、選択済みのタグをもう一度タップします。
- 絞り込んでも、いま中央にある公園は中央に残ります。
- マウスでは、ドラッグでスライドできます。

## 既知の制限

- 位置情報は取得せず、距離はダミーです(本来は現在地から算出する想定)。
- 公園の写真は、色(モノクロ版は灰色)のタイルと番号で代用しています。
- 動作確認は、ヘッドレスのChromeでの描画・操作の確認までです。実機のスマホでのスクロールの感触やスナップの挙動は確認していません。
- 公園は16件のダミーデータです。件数が大きく変わった場合のグリッドの並びは検討していません。

## Figmaに取り込む

[html.to.design](https://html.to.design/) プラグインで取り込むための、JavaScriptなしの静的HTMLです(動作はしません)。

- `figma/screens/` : 1画面1ファイル(6ファイル)。1つずつ取り込むと、それぞれが別フレームになります。取り込み時のビューポート幅は **402** にしてください。
- `figma/figma-iphone17.html` : 6画面を1ページに並べたもの。取り込むと1つのフレームにまとまります。

画面は、公園コレクション(初期・絞り込み)、公園シングル、設置遊具コレクション、遊具コレクション、遊具シングルの6つです。
